# Origin

PEHardeningReview v1.0.0 is a new, small bounded parser using Python's standard `struct` module and documented PE header fields. It does not include pefile or PEQuarry source. The earlier PEQuarry repository remains an attributed derivative of pefile with its own source and license records; its tests and provenance do not transfer to this project.

The repository owner must verify any claimed personal contribution and permission to inspect a particular binary. This is not a claim of a CVE, runtime protection, or CVP approval.
